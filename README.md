# LocalRCONServer

Консоль к игровому хосту (RCON / панель Pterodactyl). Профили остаются на устройстве.

## Скачать (один клик, ссылки не сгорают)

- ПК 0.8.1: [LocalRCONServer-0.8.1-PC.zip](https://github.com/MrAIinator/LocalRCONServer/releases/download/v0.8.1/LocalRCONServer-0.8.1-PC.zip)
- Android 0.6.1: [LocalRCONServer-0.6.1-Android.apk](https://github.com/MrAIinator/LocalRCONServer/releases/download/v0.8.1/LocalRCONServer-0.6.1-Android.apk)

ПК: распакуй ZIP и запусти `LocalRCONServer.exe` из той же папки.
Android: поставь APK (неизвестные источники).
